# Sources, location selection and continuity

## Resolve the assignment

Resolve the assignment against the files in the current project’s Sources and any files explicitly designated by the author. Check source folders and archives for the manuscript, design manual, master images and sub-location views before requesting a missing file. Capture identifiers, filenames, scope and content fingerprints so a replacement with the same filename can be detected. A version number, folder name, edit date or old delivery alone cannot determine editorial authority. If two current-looking sources disagree, apply the latest explicit correction within its scope. Ask one targeted question only when a material conflict survives inspection. Continue independent work.

| Question | Evidence to use |
| --- | --- |
| What occurs and what prints? | Assigned manuscript and scoped author corrections. Preserve its exact words, panel ownership, actor, sequence and reveal timing. |
| How should the page look and read? | Current design manual and its applicable visual examples for composition, typography, hierarchy, borders and teaching surfaces. Use the chosen current location art for palette, material, linework and finish. Use cast sheets for identity and relevant approved pages for continuity. |
| Where is it and how is it built? | Map for geography, register and image titles for candidates, the actual master and detail views for construction and camera evidence. |
| What state is it in at this instant? | Assigned beat, the preceding transition and corrections. A reusable master may depict a later repair, different lighting or a missing prop. |
| How is it delivered? | Current edition and user request for size, medium, colour, bleed, fonts, checklist and output. Use a support archive, textbook or answer key only for the job it is given. |

Read the manuscript in its own format. Interpret its field definitions before extracting copy. When instructions are embedded among spoken lines, separate the speaker, tail target and camera note from the exact spoken words. Preserve meaningful action narration, paragraph order, lists, styled runs, captions, inscriptions, equations, diagrams and blanks. Inspect native Word maths and figures or the typeset original where plain text loses structure. Link every reader-facing block to its source and placement. Account for repeated context without printing it twice. Use non-printing instructions to draw required visual evidence.

## Select an image for each scene

Build a compact index of all supplied location views. Capture the exact file or archive member, visible title, register ID when present, location, viewpoint, state and distinguishing landmarks. A contact sheet is useful for shortlisting. Inspect the selected original at full resolution. If filenames repeat, include their folder or source identity. A title printed on the image belongs to the working reference. Preserve inscriptions required inside the depicted world.

For each scene compare candidates by place, state, physical side, camera height and direction, visible contact surface and usable space for cast and lettering. Record the choice and, when ambiguous, why the nearest alternative would mislead. Separate permanent construction from temporary states. Compare the selected plate with the preceding proof at the actual crop. If a fixture, light, marking or prop shows the wrong state, correct it on the rough or flag its exact position on a non-printing overlay. Carry the change into every repeated view. Inspect that location again on the finished art before accepting it. Reuse an earlier-edition image only if the current assignment allows it and the visible design agrees.

| Treatment | Use it when | Record |
| --- | --- | --- |
| Same view | The image shows the right instant, landmarks and surface. | File, camera direction, landmarks and planned frame. |
| Crop or zoom | The required evidence is already visible. | Source crop or anchor, scale, action clearance and smallest readable detail at final size. |
| Supported new angle | The reader needs a face, relationship or contact hidden in the available view. | Camera position, what becomes visible, two spatial anchors where available, related views/map and the physical side of the action. |
| Derived or missing view | A different moment or view must be constructed. | Parent evidence, permitted change, what can be inferred and any consequential unknown. Never fill a story-critical gap with an unrelated setting. |

For a reverse view, retain physical left/right and actor handedness while screen positions change. Recheck entrances, eyelines and light direction. Do not flip a master containing directional signage, asymmetrical characters, handed props or fixed geography to manufacture a reverse angle. If only a detail is known, a tighter honest crop may solve the beat. A silent panel still needs a clear action and state.

## Maintain a short continuity record

Record the previous page's last visible action, this page's first and last actions, and the following page's first known action. Include positions, direction of travel, time/light, clothing or markings, prop possession and functional state when they affect the reader. Mark an unavailable neighbour as unknown and ground the transition in the available manuscript. Open the actual preceding approved page when available and distinguish a pending proof. Record a later correction only where it applies. Prior examples, character cameos and motifs become current only when the live assignment supports them.

When cast sheets are absent, recover an established appearance from an approved preceding page or build a consistent provisional cast reference from the manuscript. Reuse it across panels. Keep ordinary styling decisions provisional and flag a missing trait only when it changes the meaning of the scene.

Before rendering, write a short art-direction note from the current references. Use the master for the overall place and visual treatment. Use the matching sub-location for the material, colour and state visible in the assigned scene. When a maths passage names no new place, trace it to its story transition or the established setting for that teaching sequence. Record the visible features used for the page design. Apply the manual’s composition and legibility rules to those features. Preserve explicit manuscript colour meanings and any mandatory manual swatches. Compare the assembled page with the selected artwork and its neighbours.

For staging, describe each visible character's frame position and depth, focal action, expression and gaze, anatomical side, prop/contact and relation to other figures. Check comparable heights at a common depth and the support under each figure. Keep an established pose when continuity calls for it. Change the expression or movement for an identifiable reason.
