[AnswerLead] Check your method
Read what you are given and what you need in each picture:
First square: We know the area is 64 cm² and need the side, so write √64 cm. Check: 8 × 8 = 64, so the side is 8 cm.
Second square: Each side is 64 cm. To find the area, write 64² cm²: 64 × 64 = 4096.
First cube: We know the volume is 64 cm³ and need the side, so write ∛64 cm. Check: 4 × 4 × 4 = 64, so the side is 4 cm.
Second cube: Each edge is 64 cm. To find the volume, write 64³ cm³: 64 × 64 × 64 = 4096 × 64 = 262144.
