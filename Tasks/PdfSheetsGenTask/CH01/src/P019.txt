[MathSubsection] Multiplication
Let’s count some small lanterns. On the left, 2 groups of 3 give 3 + 3 = 6 lanterns. On the right, 3 groups of 2 give 2 + 2 + 2 = 6. The groups change, but the total stays 6:
[Equation] 2 × 3 = 6;   3 × 2 = 6
[SmallCaption] Six lanterns in each arrangement
[Production] Production note V05. Left: two outlined rows containing exactly three small lanterns each. Right: three outlined columns containing exactly two lanterns each. Each side contains six lanterns, not twelve in one arrangement. Label 2 groups of 3 and 3 groups of 2, with the corresponding sums. Use simple whole lantern silhouettes as ChandRush counting objects, all the same size; handles and frames are parts of each lantern. Keep the outlines that show the groups; add no extra lanterns or countable decoration. Use the current ChandRush colour and design style wherever it supports understanding. If that style would reduce clarity, retain the teaching colours, contrast and mathematical design required here. Mathematical accuracy and comprehension take priority.
The numbers we multiply are called factors; the answer is their product. We can also add the same negative change several times. For example, 3 × (−2) means three changes of −2:
[Equation] 3 × (−2) = (−2) + (−2) + (−2) = −6
