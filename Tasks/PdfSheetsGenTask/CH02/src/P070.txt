# 2.5 Comparing Fractions and Decimals
We found that 7.105 < 7.20, even though 7.105 has more decimal digits. The position of a digit matters, not the length of the number. Let’s show decimal sizes on a number line, then compare decimals with fractions.
## Comparing Decimals on a Number Line
[ProductionLabel] DO NOT PRINT — Figure reference: V19 | The following caption sentence is printable unchanged.
[Caption] Look at the interval size before reading a number line.
[ProductionNote] Production note V19 — Two uniform number lines: first 3.0 to 3.9 in steps of 0.1; second 3.20 to 3.30 in steps of 0.01. Label each tick; mark 3.1,3.3,3.6,3.7 and 3.21,3.22,3.25,3.30. Indicate second is a zoom, not the same physical unit scale. Use the current ChandRush colour and design style wherever it supports understanding. If that style would reduce clarity, retain the teaching colours, contrast and mathematical design required here. Mathematical accuracy and comprehension take priority.
Look at the top number line, from 3.0 to 3.9. Each space is 0.1. To reach 3.3 from 3.0, move 3 spaces: 3.0 → 3.1 → 3.2 → 3.3. That adds 0.1 + 0.1 + 0.1 = 0.3. On this line, 3.1 < 3.3 and 3.7 > 3.6: farther right means greater.
The lower line enlarges only the part from 3.20 to 3.30. Each small space is now 0.01. So 3.21 is 1 space after 3.20; 3.22 is 2 spaces after it; 3.25 is 5 spaces after it. The value 3.30 is the same as 3.3 on the top line. So 3.21 < 3.22, 3.25 > 3.22, and 3.3 = 3.30 > 3.21.
Check the size of a space on every number line. A longer drawing does not necessarily cover a larger number interval.
