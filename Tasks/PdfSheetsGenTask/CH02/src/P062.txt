# 2.4 Fractions and Decimals
Fractions such as 1/10, 1/100 and 1/1000 can also be written as decimals: 0.1, 0.01 and 0.001. The dot is the decimal point.
Let’s read 123.456 using the place-value table. The position of each digit tells us its value. Read the headings first: hundreds, tens, ones, tenths, hundredths, thousandths.
| Hundreds | Tens | Ones | Tenths | Hundredths | Thousandths |
| 1 | 2 | 3 | 4 | 5 | 6 |
| 100 | 20 | 3 | 4/10 | 5/100 | 6/1000 |
[Caption] 123.456 — read the place names from left to right; the decimal point belongs between ones and tenths.
[ProductionNote] Production note V15 — The table represents 123.456. Place a visible decimal-point marker between ones and tenths. Keep the digit and its value vertically aligned. Use the current ChandRush colour and design style wherever it supports understanding. If that style would reduce clarity, retain the teaching colours, contrast and mathematical design required here. Mathematical accuracy and comprehension take priority.
In 123.456, read the digits before the point: 1 hundred = 100, 2 tens = 20, and 3 ones = 3.
Now read the digits after the point: 4 tenths = 4/10 = 0.4; 5 hundredths = 5/100 = 0.05; 6 thousandths = 6/1000 = 0.006.

The second row enlarges that blue tenth so we can see inside it. Split the tenth into 10 equal parts. Each new part is 1/100 = 0.01 of the original whole, because 10 × 10 = 100.
The third row enlarges one hundredth. Split it into 10 equal parts again. Each new part is 1/1000 = 0.001 of the original whole. The drawing gets larger so we can see the cuts; the amount has not grown.
