[Question] Evaluate.
[Question] (a)  −7.86 + (−1.13)
[Question] (b)  −2.03 − (−5.92)
Let’s work it through
[WorkedStep] (a)  Start at −7.86. Adding −1.13 moves us 1.13 farther left. Add the distances below zero: hundredths 6 + 3 = 9, tenths 8 + 1 = 9, whole parts 7 + 1 = 8. That is 8.99 below zero.
[WorkedStep] −7.86 + (−1.13) = −(7.86 + 1.13) = −8.99.
[WorkedStep] (b) We need −2.03 − (−5.92). Subtracting the negative number −5.92 means adding 5.92: −2.03 − (−5.92) = −2.03 + 5.92.
[WorkedStep] Start at −2.03 on the number line and move 5.92 to the right. The first 2.03 of that move takes us from −2.03 to 0. There is 5.92 − 2.03 = 3.89 still to move, so we finish at 3.89.
[WorkedStep] Answer: −2.03 − (−5.92) = 3.89. The diagram shows the starting number −2.03, the crossing at 0 and the finish at 3.89.

[Question] (a)  2.6 + (−8.7)
[Question] (b)  −8.3 − (−2.67)
Check your method
[WorkedStep] (a)  2.6 + (−8.7) means start at 2.6 and move 8.7 left. The first 2.6 takes us to zero; 8.7 − 2.6 = 6.1 remains. So we finish at −6.1.
Answer: 2.6 + (−8.7) = −6.1. Check: −6.1 + 8.7 = 2.6.
[WorkedStep] (b)  Subtracting −2.67 means adding 2.67: −8.3 − (−2.67) = −8.30 + 2.67. The move is too short to reach zero. The distance still below zero is 8.30 − 2.67 = 5.63, so the answer is −5.63.
