# 2.7 Four Operations on Decimals
Rounding can help us estimate a calculation before we find its exact answer. Now we will add, subtract, multiply and divide decimals.
## Adding and Subtracting Decimals
In a decimal addition, add the same places: tenths with tenths, hundredths with hundredths, and so on. Write the numbers one below the other with the decimal points in one column.
A final zero can help us line up the digits. For example, 12.2 = 12.20. Both have 12 wholes and 2 tenths; the extra zero says there are 0 hundredths.
Example 20
[Question] Estimate without a calculator. Then evaluate.
[Question] (a)  12.2 + 1.43
[Question] (b)  25.2 + 1.623 + 1.2
Let’s work it through
[WorkedStep] (a) We need 12.2 + 1.43. Round 12.2 to 12 and 1.43 to 1 for an estimate: 12 + 1 = 13.
[WorkedStep] For the exact sum, write 12.2 as 12.20. Set out 12.20 and 1.43 with their decimal points one below the other, as shown in the calculation.

[WorkedStep] Start on the right, at the hundredths column: 0 hundredths + 3 hundredths = 3 hundredths.
[WorkedStep] Move left to tenths: 2 + 4 = 6 tenths. Then ones: 2 + 1 = 3 ones. Finally tens: 1 + 0 = 1 ten.
[WorkedStep] Put the decimal point below the other decimal points. The answer is 13.63: 12.20 + 1.43 = 13.63. Check by subtracting: 13.63 − 1.43 = 12.20.
[WorkedStep] (b) We need 25.2 + 1.623 + 1.2. Estimate with 25, 2 and 1: 25 + 2 + 1 = 28.
[WorkedStep] For the exact sum, write 25.200 + 1.623 + 1.200. The final zeros give all three numbers 3 decimal places without changing their values.

[WorkedStep] Start with thousandths: 0 + 3 + 0 = 3. Then hundredths: 0 + 2 + 0 = 2.
[WorkedStep] Now tenths: 2 + 6 + 2 = 10 tenths. Since 10 tenths = 1 whole, write 0 in the tenths column and carry 1 into the ones column.
[WorkedStep] Add the ones, including the carried 1: 5 + 1 + 1 + 1 = 8. The tens column gives 2 + 0 + 0 = 2.
[WorkedStep] Answer: 25.200 + 1.623 + 1.200 = 28.023. This is close to our estimate of 28. The carried 1 is worth 1 whole, not 1 tenth.
