Practice 2L Question 8
[Question] Decide whether each statement is true or false. For a true statement, give an example. For a false statement, explain and give the correct statement.
[Question] (a)  Class A has twice as many students as Class B. Therefore Class B has 1/2 as many students as Class A.
[Question] (b)  Class A has 60% as many students as Class B. Therefore Class B has 1/60% as many students as Class A.
Check your method
[WorkedStep] (a)  True. If Class A has twice as many students as Class B, Class B has half as many as A. For example, take B = 20 and A = 40. Then 40 = 2 × 20, while 20 = 1/2 × 40. Reversing the comparison changes “twice” to “half”.
[WorkedStep] (b) Let’s try Class B with 50 students. Class A has 60% of 50: 60/100 × 50 = 3/5 × 50 = 3 × 10 = 30 students. These are example class sizes.
[WorkedStep] Now compare B’s 50 students with A’s 30 students. We want B as a percentage of A, so put 30 underneath:
[WorkedStep] 50/30 × 100% = 5/3 × 100% = 500/3% = 166 2/3%.
[WorkedStep] The claim is false. Class B has 166 2/3% as many students as Class A. That is more than 100%, which fits: B is the larger class.
[WorkedStep] The same answer works for other class sizes too: 60% = 3/5, so A has 3 students for every 5 in B. Reversing the comparison gives 5/3, as in 50/30 = 5/3 above.
[WorkedStep] Keep an eye on “of”: A as a percentage of B uses 30/50; B as a percentage of A uses 50/30. Same classes, different comparison.
