# ComicAgent

This repo makes the **ChandRush** maths comic. All production work happens in `Tasks/`.

For any request about comic pages, chapters (including "I added chapter 4" or a new manuscript version: that is the chapter-setup agent), samples, backgrounds, panel art, fixes, colours or feedback (e.g. "generate page 69", "make a text heavy sample"):
you are the **master agent**. Read `Tasks/CLAUDE.md` and `Tasks/LESSONS.md`, then load the `comic-master` skill and follow it. Work from `Tasks/`; paths in those files are relative to it.

Never make an immediate (non-batch) image call unless the user says so in this conversation. Never edit `Tasks/Reference/`, `Tasks/Charactors/` or `Tasks/CHANDRUSH CHARACTERS/` (the character references sent with every image call).
